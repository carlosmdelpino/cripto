# Criptografía Postcuántica

Este repositorio sirve como base para estudiar, experimentar y documentar conceptos relacionados con la criptografía postcuántica.

## Objetivo

Explorar los principales algoritmos, modelos de seguridad y aplicaciones prácticas de la criptografía diseñada para resistir ataques de computación cuántica.

## Enfoque del proyecto

La idea es trabajar de forma progresiva:

1. Comprender los fundamentos de la computación cuántica y sus implicaciones en la criptografía clásica.
2. Estudiar algoritmos postcuánticos clave: Kyber, Dilithium, Falcon y SPHINCS+.
3. Implementar demostraciones simples y experimentos educativos.
4. Evaluar ventajas, riesgos y casos de uso reales.
5. Documentar conclusiones y comparaciones entre enfoques.

## Estructura inicial

- `src/pqc`: módulos con utilidades y conceptos básicos.
- `examples`: scripts de demostración.
- `docs`: documentación y hoja de ruta.

## Requisitos

- Python 3.10+
- Dependencias mínimas definidas en `requirements.txt`

## Ejecución rápida

```bash
python examples/basic_demo.py
```
