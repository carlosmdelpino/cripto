# Word y documentación docente

Esta carpeta está preparada para albergar los documentos Word finales de cada clase y de la asignatura.

## Estructura sugerida

- 00_portada.docx
- 01_clase_1_fundamentos_criptografia.docx
- 02_clase_2_criptografia_moderna.docx
- 03_clase_3_computacion_cuantica.docx
- 04_clase_4_criptografia_postcuantica.docx
- 05_clase_5_metodos_postcuanticos.docx
- 06_clase_6_nist_pqc.docx
- 07_documento_situacion_negocio.docx
- 08_casos_practicos.docx
- 09_test_conocimientos.docx
- 10_proyecto_final_asignatura.docx

## Recomendación de contenido para cada Word

Cada documento debe incluir:

- portada y estructura
- introducción
- objetivos
- desarrollo teórico
- ejemplos prácticos
- ejercicios
- diagramas o esquemas
- conclusiones
- bibliografía
- preguntas de reflexión

## Nota

Los archivos Word pueden generarse a partir de estos contenidos y posteriormente completarse con ejemplos y casos reales del docente.
