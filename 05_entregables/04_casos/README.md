# Casos prácticos

Esta carpeta recoge los casos con enunciado y resolución para la docencia del curso.

## Distribución por temas

Cada caso práctico cubre dos temas consecutivos del programa, de manera que con las tres actividades se cubren los seis documentos temáticos:

- Caso 1: Temas 1 y 2
- Caso 2: Temas 3 y 4
- Caso 3: Temas 5 y 6

## Estructura actual

- caso_unidad_1_enunciado.ipynb
- caso_unidad_1_solucion.ipynb
- caso_unidad_2_enunciado.ipynb
- caso_unidad_2_solucion.ipynb
- caso_unidad_3_enunciado.ipynb
- caso_unidad_3_solucion.ipynb
- caso_final_enunciado.ipynb
- caso_final_solucion.ipynb

## Qué incluye cada caso

Cada caso tiene dos notebooks separados:

- Enunciado: ejercicio para el alumnado con el planteamiento, datos y tareas a resolver.
- Solución: resolución desarrollada, con explicación y una implementación en Python.

## Objetivo pedagógico

- Integrar dos bloques temáticos en un mismo ejercicio.
- Relacionar conceptos teóricos con su aplicación práctica.
- Preparar un caso final que consolide la asignatura y la transición a la criptografía post-cuántica.
