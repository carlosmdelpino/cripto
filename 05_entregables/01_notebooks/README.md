# Notebooks del curso

Esta carpeta contiene las entregas en formato notebook para cada clase.

## Estructura prevista

- 01_clase_1_fundamentos_criptografia.ipynb
- 02_clase_2_criptografia_moderna.ipynb
- 03_clase_3_computacion_cuantica.ipynb
- 04_clase_4_criptografia_postcuantica.ipynb
- 05_clase_5_metodos_postcuanticos.ipynb
- 06_clase_6_nist_pqc.ipynb
- 07_test_final_asignatura.ipynb
- 08_caso_final_asignatura.ipynb

## Enfoque de cada notebook

Cada notebook debe incluir:

1. Introducción teórica breve
2. Ejercicios matemáticos
3. Ejemplos prácticos
4. Cálculos con Python
5. Visualizaciones sencillas
6. Cierre con conclusiones
7. Preguntas de reflexión

## Recomendación

Usar Python con bibliotecas como:
- numpy
- matplotlib
- sympy
- pandas

Ejemplo de instalación:

```bash
pip install numpy matplotlib sympy pandas
```
